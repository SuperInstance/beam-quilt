# Digest — the Gemini rounds (docs/proposed + chrono-tensor ideation)

*Read 2026-10-21: all 22 files in `docs/proposed/` (~100k words) and the three
ideation documents in `SuperInstance/chrono-tensor` (~17.5k words), checked
against beam-quilt v0 (README + SPEC). Verdict first, evidence after.*

## The headline

Roughly **75–85% of the corpus is restatement** — of v0, then of itself, each
file re-deriving the previous one at a grander scale. The genuinely new
material is real but concentrated, and it falls into three piles: names for
things v0 left unnamed, a handful of mechanisms v0 lacked, and one product
idea (in chrono-tensor) that is better than the ontology wrapped around it.
The physics vocabulary — standing waves, moiré superlattices, Hodge
decompositions, Kuramoto entrainment, Laman-rigidity-as-truth, Eisenstein
snapping — **adds no mechanism anywhere it appears**. In every case it
reduces to something v0 already says in plain words (several assessments
combined; disagreements counted; rounding a value; nodes adjusting cadence).
None of it should enter the spec.

## Conflicts that need a ruling before any amendment

1. **What the deadband means.** v0 SPEC §3: landing in the deadband triggers
   a clarification / scope-distillation query. gemini15 says landing inside
   means *do nothing, abstain, coast*, and gemini17 merges the accept band
   and the deadband into one silent absorption. Three incompatible outcomes
   wearing one name. **Ruling needed:** clarify (v0), or add *abstain* as a
   distinct fourth outcome alongside it.
2. **Where state lives.** gemini4/20/21: state is purely transient, carried
   in the envelope; "state vanishes, prompts vanish." SPEC P4/P5: patches
   *hold* sovereign state and keep their own logs. The wave version deletes
   the memory — logs, disagreement records, the C3 stop test — that the rest
   of the design depends on. Recommendation: v0 stands.
3. **What crosses a seam.** gemini8/9: raw latent vectors between different
   models, "without shared calibration" — while also proposing a negotiated
   transition matrix, which *is* calibration. v0 chose typed profiles and
   questions precisely because latent spaces aren't shared. Latent seams stay
   an explicitly priced research option, not the default.
4. **Receiver scoring.** The Gemini formalism quietly replaces SPEC's
   *comparative* pick (against the competing pool) with an absolute score
   against fixed thresholds — a weaker mechanism in the same notation. v0
   stands.
5. **The hologram returns.** gemini15: "each node is a full reflection of
   the topology." docs/07 already rejected this for sharding. Rejected
   again.
6. **Consent disappears.** After gemini19, rules C1–C3 (enrolment, COPY
   never a default, haltability) essentially vanish and replication becomes
   ambient. In v0, consent/opacity/irreversibility is the whole safety axis.
   Non-negotiable.
7. **Scope.** v0: implementation deliberately out of scope. gemini17/21/22
   specify production runtimes three incompatible ways (Python quilt-engine,
   Rust continuum-runtime, C99 edge filter). Any build is a scope decision,
   not an implication.

Also rejected on evidence: deterministic replay of LLM behaviour (sampling
is nondeterministic; g4 asserts exact replay without logging seeds),
"immune to network splits / zero latency" absolutes (g2/g4/g6 — a
partitioned node cannot receive proposals; local survival is not continued
coordination), the O(N²)-escape formula (stated, never derived; patches
containing LLMs still pay their own attention), "truth is a rigid graph"
(a rigid constraint graph can be rigidly wrong), and the PLATO/TUTOR
lineage claims in chrono-tensor gemini2/3 (repeated verbatim, unsourced,
carrying argumentative weight they haven't earned).

## Chrono-tensor: what it is relative to beam-quilt

**A rival ontology on paper; in practice, a component — and a good one.**

As written, CTC demotes beam-quilt to a subsystem and replaces its
ontology (trajectory-only state, time-first, Track 16 "Master Conductor"
regulating global tempo — the central authority the same texts claim to
abolish; MIDI's 3 KB/s cited as enabling "sub-millisecond alignment" argues
against itself). That ontology should not be adopted.

But its concrete artifacts are exactly the layer beam-quilt v0 lacks and
its SPEC already demands (P5 logs, C2 visible seams):

- **The 4D event**: every state change as `[time/tick, channel/agent,
  pitch/intent, velocity/pressure]` — a transmission record format.
- **Chrono-flight**: the fleet's black box — everything recorded as one
  scrubbable multi-track stream. Debugging = rewind, mute a track, replay.
- **Temporal downmixing**: old history compressed into background stems,
  recent events at full fidelity — a concrete answer to v0's open question
  about log growth (P5's declared garbage-collection rate).

Recommendation: chrono-tensor becomes beam-quilt's **time, logging, and
observability layer**, and chrono-flight is the first product-shaped thing
in the whole programme: a recorder for a fleet that already exists (the
agent fleet's runs are today scattered across transcripts and cron logs).
The continuum ontology, the lattice routing, and the conductor stay parked
in the ideation folder where Casey put them.

## Proposed sequence

1. **Rule on the deadband** (conflict 1) — the only blocker for a spec
   amendment.
2. **SPEC v1.1 amendment**: Reality Matrix + Campaign Manifest as the node
   context structure; Scar; minimum-link confidence (scoped); closure as
   the ledger test; dynamic deadband; event-driven silence; Abstain if
   ruled in. A new chapter (10) adopting chrono-flight as the temporal
   layer, crediting chrono-tensor as its source repo.
3. **First build, when scope is granted**: the pair Gemini's own most
   grounded file (g6) converged on and v0 already implies — a
   `TransmissionEnvelope` + `JevPair` reference implementation, two
   processes, no shared memory, accept/reject/deadband demonstrated — with
   chrono-flight recording the run so the first quilt experiment is itself
   scrubbable.
